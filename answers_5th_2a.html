Task 3｜ビューの実装

30点

解答パターンA：FBV

参照：Chapter 3 リスト3.4, リスト3.6 [p.84-85]
Python 
from django.shortcuts import render, redirect
from .models import Task
from .forms import TaskForm

# ① タスク一覧画面
def task_list(request):
    tasks = Task.objects.all()
    return render(
        request,
        'taskapp/task_list.html',
        {'tasks': tasks}
    )

# ② タスク新規登録画面
def task_create(request):
    if request.method == 'POST':
        form = TaskForm(request.POST)

        if form.is_valid():
            form.save()
            return redirect('task_list')
    else:
        form = TaskForm()

    return render(
        request,
        'taskapp/task_form.html',
        {'form': form}
    )
一覧側は {'tasks': tasks} 、登録フォーム側は {'form': form} としてテンプレートへ渡します。

解答パターンB：CBV

参照：Chapter 7 リスト7.11 [p.196] / Chapter 8 リスト8.1 [p.207] / Chapter 8 リスト8.14 [p.226]
Python 
from django.views.generic import ListView, CreateView
from django.urls import reverse_lazy
from .models import Task
from .forms import TaskForm

# ① タスク一覧画面
class TaskListView(ListView):
    model = Task
    template_name = 'taskapp/task_list.html'
    context_object_name = 'tasks'

# ② タスク新規登録画面
class TaskCreateView(CreateView):
    model = Task
    form_class = TaskForm
    template_name = 'taskapp/task_form.html'
    success_url = reverse_lazy('task_list')
context_object_name = 'tasks' と form_class = TaskForm が問題編の指定に対応しています。 fields は指定しません。

Task 5｜テンプレートを完成させる

33点

問題編では、HTML全体を一から作成するのではなく、指定された【空欄】をDjangoテンプレート記法で補完します。

task_form.html ｜3つの空欄 

空欄1  →  {% csrf_token %}
空欄2  →  {{ form.as_p }}
空欄3  →  {% url 'task_list' %}

task_list.html ｜5つの空欄 

空欄1  →  {% url 'task_create' %}
空欄2  →  {% for task in tasks %}
空欄3  →  {{ task.title }}
空欄4  →  {{ task.due_date }}
空欄5  →  {% endfor %}

完成形①｜ task_form.html

HTML / Django Template 
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <title>タスク登録</title>
</head>
<body>
    <h1>タスク新規登録</h1>

    <form method="post">
        {% csrf_token %}

        {{ form.as_p }}

        <button type="submit">追加</button>
    </form>

    <br>

    <a href="{% url 'task_list' %}">
        一覧に戻る
    </a>
</body>
</html>
{ form.as_p } は、Task 3のビューから form という名前で渡されたフォームを表示します。 {% csrf_token %} はPOSTフォームで必要なCSRF保護です。

完成形②｜ task_list.html

HTML / Django Template 
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <title>タスク一覧</title>
</head>
<body>
    <h1>タスク一覧</h1>

    <a href="{% url 'task_create' %}">
        新規登録
    </a>

    <hr>

    <ul>
        {% for task in tasks %}

            <li>
                {{ task.title }}
                -
                期限:
                {{ task.due_date }}
            </li>

        {% endfor %}
    </ul>
</body>
</html>
{% for task in tasks %} の tasks は、Task 3でFBVなら {'tasks': tasks} 、CBVなら context_object_name = 'tasks' とした部分に対応します。
日付表示： { task.due_date } の表示形式は環境・テンプレート記述によって 2026-10-20 や 2026年10月20日 などになり得ます。 問題編では表示形式そのものは採点対象としていません。
