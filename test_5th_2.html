事前準備

PROJECT SETUP · 試験時間に含む

1. 作業用フォルダを作成し、VS Codeで開く

任意の場所に試験用の空フォルダを作成し、そのフォルダをVS Codeで開きなさい。

フォルダ名は任意です。以降のコマンドは、作成した空フォルダをVS Codeで開いた状態で実行してください。

2. Djangoプロジェクトを新規作成する

Terminal 
django-admin startproject myproject

実行後、作業フォルダ内に myproject フォルダが作成されていることを確認すること。
上のコードで実行できない場合は python -m django-admin startproject myproject と入力してください。

3. プロジェクトフォルダへ移動する

Terminal 
cd myproject

以降の manage.py を使うコマンドは、この myproject フォルダ内で実行すること。

4. taskapp を作成する

Terminal 
python manage.py startapp taskapp

5. アプリをプロジェクトへ登録する

myproject/settings.py の INSTALLED_APPS に 'taskapp' を追加すること。

6. 言語とタイムゾーンを設定する

myproject/settings.py を開き、 LANGUAGE_CODE を 'ja'、 TIME_ZONE を 'Asia/Tokyo' に変更すること。既存の設定項目は削除しないでください。 

作業フォルダ/
└── myproject/
    ├── manage.py
    ├── myproject/
    │   ├── settings.py
    │   └── urls.py
    └── taskapp/
        ├── models.py
        └── views.py
環境について： この試験では仮想環境は使用しません。また、Djangoのインストール作業も試験範囲外です。各PCの実環境に用意されたPython / Djangoをそのまま使用してください。
django-admin startproject myproject を実行すると、作業フォルダ内に myproject フォルダが作成されます。その後、必ず cd myproject で移動してから manage.py を使うコマンドを実行してください。

実技課題

IMPLEMENTATION
01
MODEL & DATABASE

モデルの作成とマイグレーション

20 pts

taskapp/models.py に、次の仕様を満たす Task モデルを定義し、データベースへ反映させなさい。

項目 フィールド名 仕様
タイトル title 文字列型、最大50文字
期限 due_date DateField
完了状態 is_completed 真偽値型、デフォルト値は False
__str__ メソッドを定義し、オブジェクトの文字列表現として title を返すこと。
モデル定義後、 makemigrations と migrate を実行してテーブルを作成すること。
02
MODELFORM

入力フォームの作成

15 pts

taskapp/forms.py を 新規作成 し、 ModelForm を使って TaskForm を実装しなさい。

Task モデルに基づく forms.ModelForm を継承すること。
入力対象フィールドは ['title', 'due_date'] とし、 is_completed はフォームから除外すること。
due_date には forms.DateInput(attrs={'type': 'date'}) を使用し、ブラウザのカレンダー入力を利用できるようにすること。
03
VIEW

一覧表示と新規登録ビューの実装

30 pts

taskapp/views.py に次の2つの処理を実装しなさい。 FBV（関数ベースビュー）またはCBV（クラスベースビュー）のどちらを使用しても構いません。

① タスク一覧画面

登録されているすべての Task データを取得すること。
taskapp/task_list.html を表示し、テンプレート側では取得データを tasks という名前で参照できるようにすること。
FBVの場合はコンテキスト辞書のキーを tasks にすること。CBVの場合は context_object_name = 'tasks' とすること。

② タスク新規登録画面

TaskForm を使用し、 taskapp/task_form.html を表示すること。
GET時は空のフォームを表示し、POST時は送信データを検証して、妥当であれば保存すること。
保存成功後は、URL名 task_list の一覧画面へ移動すること（PRGパターン）。
FBVの場合は、フォームをコンテキスト辞書のキー 'form' としてテンプレートへ渡すこと。CBV（ CreateView ）を使用する場合は、Task 2で作成したフォームを適用するため form_class = TaskForm を指定し、 fields は指定しないこと。FBV・CBVで採点上の有利不利はありません。
04
URL ROUTING

URLルーティングの設定

15 pts

プロジェクト側とアプリ側のURL設定を行い、次の構造を完成させなさい。

myproject/urls.py では include() を使い、 tasks/ 以下の処理を taskapp.urls に委任すること。
taskapp/urls.py は自動生成されないため、 新規作成 すること。
/tasks/ → タスク一覧画面　name='task_list'
/tasks/create/ → タスク新規登録画面　name='task_create'
